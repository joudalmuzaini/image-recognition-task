# Image Recognition Task

## Description
This project trains an image recognition model using Google's Teachable Machine, 
then uses a Python script to load the model and predict the class of a new image.

## Steps
1. Trained a model with 2 classes using Teachable Machine
2. Exported the model in TensorFlow/Keras format
3. Wrote a Python script (predict.py) to load the model and classify a new image
4. Tested the model and captured the output

## Files
- `predict.py` - Python script that loads the model and makes predictions
- `keras_model.h5` - Trained model file
- `labels.txt` - Class labels
- `test_screenshot.png` - Screenshot showing the script output
